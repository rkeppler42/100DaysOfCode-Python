# 🎸 Band Name Generator

This is the project for **Day 01** of the course  
**“100 Days of Code: The Complete Python Pro Bootcamp”**.

The goal is to build a simple Python program that generates a band name by combining:

- The city where the user grew up
- The name of a pet

---

## 🧠 What I Learned

- How to use the `print()` function
- How to collect user input with `input()`
- How to store user responses in variables
- How to concatenate strings
- How to add line breaks using `\n`
- Basic debugging and small code improvements

---

## 🛠️ Requirements

The final program must:

1. Display a greeting message:
   `Welcome to the Band Name Generator.`

2. Ask the user for:

- The city they grew up in
- The name of a pet

3. Store both answers in variables.

4. Combine the values into a single string to generate a band name:
   `Your band name could be: City Pet`

5. Ensure that **each input shows the cursor on the next line**.

```
Welcome to the Band Name Generator.
Which city did you grow up in?
> Salvador
What's the name of a pet?
> Bob
Your band name could be: Salvador Bob
```
