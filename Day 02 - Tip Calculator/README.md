# 🧮 Tip Calculator

This is the project for **Day 02** of the course  
**“100 Days of Code: The Complete Python Pro Bootcamp”**.

The program calculates how much each person should pay when splitting a bill, including a tip percentage chosen by the user.

---

## 🧠 What I Learned

- Using `input()` to collect user data  
- Converting strings to numerical types (`int`, `float`)  
- Performing percentage calculations  
- Understanding floating-point behavior in Python  
- Using the `round()` function for decimal formatting  
- Building readable output with f-strings  
- Applying operator precedence (PEMDAS)  

---

## 🛠️ Requirements

The final program must:

1. Display the greeting:

`Welcome to the tip calculator!`

2. Ask the user for:
- The **total bill**  

- The **tip percentage**  

- The **number of people** splitting the bill  
3. Convert the inputs into numerical types for calculation:
- Bill → `float`  

- Tip → `int`  

- People → `int`  
4. Compute the total bill with tip:
- Convert tip percentage into a decimal  

- Multiply bill by `(1 + tip/100)`  
5. Divide the total by the number of people.

6. Round the final value to **two decimal places**.

7. Format and print the result:
   
   `Each person should pay: $<amount>`



---

## 📝 Example Output

```
Welcome to the tip calculator!
What was the total bill? $124.56
What percentage tip would you like to give? 12
How many people are splitting the bill? 7
Each person should pay: $19.93
```
